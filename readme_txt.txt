download the zip file and extract the files into a seperate folder.
you will find two batch files, two python files, two folders named images and pictures in it.

batch_aminusbsq.bat is for creating slides for (a-b)^2
batch_aplusbsq.bat is for creating slides for (a+b)^2

you need to set appropriate folders in these files.

Python files you dont need to make any modifications.

pictures folder is where you need to put your images for which you need to creat a presentation or 
select the name of the images in pictures and put their names in the batch file. 

images folder is the output folder where your output images will be stored

you need to have python installed on your machine and you also need the modules named pillow and python-pptx

from command prompt run the following commands 

python -m pip install python-pptx
python -m pip install Pillow
